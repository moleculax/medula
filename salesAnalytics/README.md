## 🚀 Características Principales

| Característica | Descripción |
|----------------|-------------|
| **Carga de Datos** | Importa archivos CSV/Excel con datos de ventas |
| **Dashboard Interactivo** | Visualiza métricas clave (ventas totales, productos top, etc.) |
| **Filtros Dinámicos** | Filtra por fecha, producto, categoría, región o vendedor |
| **Gráficos Automáticos** | Genera gráficos de barras, líneas, torta y dispersión |
| **Estadísticas Descriptivas** | Calcula promedios, totales, máximos, mínimos y tendencias |
| **Exportación de Reportes** | Descarga reportes en PDF, Excel y CSV |
| **Autenticación JWT** | Sistema de login seguro con tokens JWT |
| **API REST** | Endpoints para integración con React, Vue o apps móviles |
| **Documentación Swagger** | API documentada con Swagger/OpenAPI |
