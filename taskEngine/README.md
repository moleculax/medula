## Descripcion

**TaskEngine** es una plataforma de automatizacion inteligente que integra Inteligencia Artificial, analisis de datos y procesamiento de documentos en un solo ecosistema. Diseñado para optimizar procesos empresariales y facilitar la toma de decisiones basada en datos.

### Que puedes hacer con TaskEngine?

- Analizar CVs con IA usando LangChain y Groq
- Visualizar datos con graficos estadisticos avanzados
- Procesar documentos PDF y Excel
- Automatizar tareas repetitivas con inteligencia artificial
- Gestionar datos con bases de datos SQLite y PostgreSQL

## Tecnologias

### Backend & Frameworks
- **Django** - Framework web robusto y seguro
- **LangChain** - Framework para aplicaciones con LLMs
- **LangChain-Groq** - Integracion con Groq para inferencia rapida

### Analisis de Datos
- **Pandas** - Manipulacion y analisis de datos
- **NumPy** - Computacion numerica y arrays

### Visualizacion
- **Matplotlib** - Graficos basicos
- **Seaborn** - Graficos estadisticos avanzados

### Procesamiento de Documentos
- **PyPDF2** - Lectura y manipulacion de PDFs
- **Openpyxl** - Manejo de archivos Excel

### Bases de Datos
- **SQLite** - Base de datos ligera para desarrollo
- **PostgreSQL** - Base de datos robusta para produccion
