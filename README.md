## 📊 SalesAnalytics

**SalesAnalytics** es una plataforma de analítica de ventas desarrollada con Django, Python, LangChain y Groq.

### 🔗 Demo
- 🌐 **Web**: https://pdfhand2.pythonanywhere.com

### 📦 Código Fuente
El código fuente de SalesAnalytics está disponible bajo **licencia MIT** mediante un **pequeño aporte monetario** que permite financiar el desarrollo continuo.

**Qué incluye:**
- 📂 Código fuente completo de la aplicación Django
- 🗄️ Scripts de base de datos (SQLite, PostgreSQL, MariaDB)
- 📊 Módulos de análisis con LangChain y Groq
- 🎨 Templates y assets para el frontend
- ⚙️ Configuraciones para entornos de desarrollo y producción

**Modalidad de acceso:**
- 💰 Aporte único (sin suscripciones)
- 📄 Licencia MIT
- 🔓 Libertad total para usar, modificar y distribuir
- ⚠️ Software "TAL CUAL" (AS IS), sin garantías

## 🍽️ MenuAdmin

**MenuAdmin** es un sistema de gestión para restaurantes que permite administrar menús digitales y generar códigos QR dinámicos. Desarrollado con Next.js, Spring Boot y PostgreSQL.

### 🔗 Demo y Documentación
- 🌐 **Web**: https://menuadmin.com

### 📦 Código Fuente
El código fuente completo de MenuAdmin estará disponible en su totalidad mediante el establecimiento de un **aporte monetario** que permita financiar el desarrollo continuo de la plataforma.

**Qué incluye:**
- 📂 Código completo: Frontend (Next.js) y Backend (Spring Boot)
- 🗄️ Scripts de base de datos para PostgreSQL
- 🐳 Configuración Dockerfile
- 📄 Documentación técnica
- 🔧 Configuraciones de entornos

**Modalidades de acceso:**
1. **Licencia Individual**: Para emprendedores y pequeños negocios
2. **Licencia Empresarial**: Para organizaciones que deseen implementar la solución internamente
3. **Licencia de Desarrollo**: Para equipos que deseen extender la funcionalidad
