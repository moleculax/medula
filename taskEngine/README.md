## Descripcion

**TaskEngine** es un sistema de automatizacion  construido con Django que integra:

- Inteligencia Artificial con LangChain y Groq
- Analisis de datos con Pandas, NumPy y Matplotlib
- Procesamiento de PDFs con PyPDF2
- Base de datos SQLite para desarrollo
- Base de datos Postgres para produccion
- Graficos estadisticos con Seaborn
